# Pipeline Claude

## Rules

- Every pipeline codebase must collect the following metrics into a dataframe and upload the set into a snowflake database: MONITORING.HISTORY.PIPELINE_RUN_HISTORY
- Every pipeline must upload its metric dataset regardless of pipeline success or failure or any other condition.
- Every pipeline codebase must have the following
  - Generate the pipeline_run_id at runtime
  - Once a dataset has been extracted from the datasource the code will generate a hash id from the dataset's contents; and another hash id based on each row's data.
  - Once all of the metrics have been collected/generated the pipeline_run_id, the end_time, batch_hash_id, and source_id are appended as columns to the extracted dataset for data lineage purposes.


## Metrics

The purpose of the metrics generated/captured at runtime is to provide performance data about the pipeline at runtime so that performance can be monitored. Additionally, UUID's and Hash ID's are
generated to provide both data lineage services and distinguish between the different pipelines.

## MONITORING.HISTORY.PIPELINE_RUN_HISTORY Schema

Column                    |  Data Type        |  Description

|  Pipeline_Run_id        |  Int              |  A uuid generated every pipeline run at runtime
|  Source_id              |  Int              |  A unique id for the data source; is only unique per data source; it is not generated, it is given via environment variables
|  Batch_Hash_ID          |  Var              |  A hash number generated by the contents of the dataset extracted from the source
|  Row_Hash_ID            |  Var              |  A hash number generated by the contents of every row in the dataset
|  Run_Status             |  Text             |  A status column that shows the processing status of the pipeline (e.g. success, failed)
|  Error_Message          |  Text             |  If a pipeline run failed, its error status is uploaded into this column
|  Start_Time             |  Datetime         |  The start time of the pipeline run
|  End_Time               |  Datetime         |  The end time of the pipeline run
|  Duration               |  Time (Seconds)   |  The total duration of the pipeline run
|  Number_of_Columns      |  Int              |  The number of columns found in the dataset
|  Number_of_Rows         |  Int              |  The number of rows found in the dataset
